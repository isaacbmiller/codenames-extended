# Word Sources

The bundled English word pack in this project is based on curated Codenames-style sources discovered during planning:

- `jacksun007/codenames`: https://github.com/jacksun007/codenames
- `sagelga/codenames`: https://github.com/sagelga/codenames
- KodeNames wordlist reference: https://kodenames.io/wordlist/

The local bundle is family-safe only and is normalized for gameplay:

- case-insensitive deduplication
- trimmed whitespace
- removal of explicit/adult entries
- removal of low-signal punctuation variants
